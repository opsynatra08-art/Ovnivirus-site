The website lists the eight tracks in tracks.json. WAV files are served from the
"audio-v1" GitHub Release for opsynatra08-art/Ovnivirus-site, keeping large audio files
out of the website's Git history.

Attach each WAV to the release using the exact filename listed in tracks.json. Each
release asset must be under 2 GiB.

The Free Pack opens through the shared TeraBox link. Do not add the original ZIP to the
repository; it is approximately 122 MB.

To update the music, add new assets to a release, update tracks.json, and publish the
website changes.
